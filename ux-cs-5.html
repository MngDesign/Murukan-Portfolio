Case study 5
BCAP -Bulk Cargo Planning Application
Transforms Operations are Planned, Optimized, and Executed

Bulk cargo vessels have complex cargo holds with various constraints. BCAP helps planners maximize space efficiency, ensuring the vessel carries the maximum safe load while maintaining balance and stability.

INDUSTRY:
Marine Cargo shipping
CATEGORY:
Responsive Web application for all devices
MARKET:
Global
USERS:
Voyage Planners, Port Captains and Operations Coordinators
UI UX ROLE:
Requirement analyse, Sketches, UX Research, Wireframe, Visual designig and Interactin designing.
Challenges
  • Complex Interface & Cognitive Overload
    Poor Information Architecture -Difficulty finding frequently used features like saved voyages, templates, or team permissions.

  • Complex Interface & Cognitive Overload
    Cargo planning involves multiple variables — cargo types, densities, hold capacities, trim, list, draft, ballast, port constraints, etc.
    If the interface is cluttered or overly technical, users may struggle to locate functions or interpret data visualizations.
    Too many manual inputs or scattered data fields can lead to frustration and slower workflows.

  • Steep Learning Curve/b>
    Lack of contextual help or tooltips can make first-time use intimidating.

  • Limited Real-Time Feedback or Validation
    Real-time “what-if” simulations are crucial but sometimes missing or slow.
    If the system doesn’t instantly flag violations, users might only discover errors at later stages — leading to costly rework.

  • Missing automation for data imports
    Data inconsistency between BCAP, voyage management systems, port databases, or ERP tools causes confusion and manual corrections.

  • Visualization & Interpretability Challenges
    Inadequate 3D or schematic visualization of cargo distribution can make it hard to understand weight balance intuitively.     Users prefer visual cues (color codes, warnings, overlays) rather than raw numerical tables — many tools lack this.

  • Lack of Customization or Flexibility
    Different vessels, cargo types, and port operations need tailored logic. A rigid system without user-defined templates, rules, or preferences reduces practical usability and adaptability.

Solution

  • Simplifyed & Prioritized the Interface to reduce Cognitive Overload Ensured clean visual hierarchy and consistent iconography.
    Introduce dashboard summaries with quick overviews (draft, trim, tonnage, etc.).

  • Guided Onboarding Added interactive walkthroughs, tooltips, and tutorials for first-time users. Useed contextual help (hover or click for explanations).

  • Instant Validation Integrateed real-time rule checks (e.g., trim balance, draft limits, port restrictions).
    Used color-coded alerts (green = valid, red = critical error, yellow = warning).

  • Intuitive Visual Design Added 2D/3D visual stowage diagrams for easy spatial understanding.
    Used color-coded cargo visualization by type, density, or port.
    Provideed graphical stability curves and trim visualizations.

  • Streamlined Workflow Navigation sidebar with logical grouping
    keyboard shortcuts for expert users.

  • Error Visibility Aand Clear Feedback Error messages with causes and suggestions.
    Added autosave and recovery features for crash protection.
    Highlight affected parameters visually when an error occurs.
Results

  • Improved User Efficiency & Faster Planning Planners can create and modify cargo plans in significantly less time.

  • Higher Ease of Use & Reduced Cognitive Load Simplified interface and guided workflows help users focus on decision-making rather than system handling.
    Users find the system more intuitive, predictable, and less error-prone.
    New users achieve proficiency faster, lowering training and onboarding effort.

  • Enhanced Collaboration & Communication Fewer communication delays, everyone works on the same updated plan.

  • Better Decision-Making with Visual Insights Enhanced 2D/3D visualizations make cargo distribution and stability easy to interpret visually.
    Color-coded and graphical indicators allow instant assessment of vessel status.

  • Improved Performance & Reliability Better performance builds user trust and satisfaction.
    Overall improvement in operational reliability and safety.

  • Higher User Satisfaction & Adoption Users find the application easier, faster, and more pleasant to use.
    Increased confidence and adoption rates across departments.

  • Business-Level Impact Reduced port stay and rework costs → Operational Savings.
    Increased voyage efficiency → Higher Profitability per trip.
    Strengthened reputation and trust with clients, charterers, and port authorities.
