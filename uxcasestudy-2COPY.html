G2 OCEAN- Fleet Management Application
Redesign to improve usability and increase customer engagement.
Positive Impact +25% user engagement, +40% task completion rate, 30% reduction in support calls
Tools: Figma, Locafy, Figjam, Adobe CC, HTML, CSS

G2O Shipping is a bulk carrier shipping company that uses this application for its stowage and voyage planning operations. The platform helps the team efficiently manage cargo distribution, optimize vessel performance, and ensure safe and compliant voyages."

DOMAIN:
Marine Cargo shipping
PROJECT TYPE:
Responsive Web application
USER:
Voyage Planners, Port Captains and Operations Coordinators
MY ROLE:
Requirement analyse, Sketches, UX Research, Wireframe, Visual designig and Interactin designing.
Requirement and first level of Maping
Background: This application is a Responsive web application for the use of Voyage Planners, Port Captains and Operations Coordinators. By this applicatin they can manage Planning, Designing the Stowage and Cargo plan for each voyage more efficiantly.
Product story:
Orchestrating every voyage with intelligent cargo planning for safer, faster, and more efficient marine operations
User story:
As a voyage planner, I want to intelligently design and optimize cargo stowage so that each voyage is executed safely, efficiently, and on schedule.
