Case study 4
Profile of Voyage Planner
Voyage Planner is the brain behind the fleet’s movement — turning complex global operations into smooth, synchronized voyages.

A Marine Fleet Planner’s profile is a blend of technical, analytical, and operational expertise, making it uniquely valuable in the maritime ecosystem.

INDUSTRY:
Marine Cargo shipping
CATEGORY:
Responsive Web application for all devices
MARKET:
Global
USERS:
Voyage Planners, Port Captains and Operations Coordinators
UI UX ROLE:
Requirement analyse, Sketches, UX Research, Wireframe, Visual designig and Interactin designing.
Challenge
  • Poor Information Architecture -Difficulty finding frequently used features like saved voyages, templates, or team permissions.

  • Limited Personalization Options

  • Ineffective Notification Management

  • Inefficient Profile Update Process -Updating information like team assignments, availability, or designation requires admin intervention.

  • Poor Mobile or Cross-Platform Support

  • nadequate Feedback & Error Handling- No clear confirmation or feedback after making updates (e.g., “Profile saved successfully”). Errors during saving or syncing are shown with technical messages instead of human-readable guidance. Auto-save doesn’t always work, leading to lost profile changes.
Marine Fleet Planners face usability friction mainly around navigation, personalization, role clarity, feedback, and transparency when managing their own user profile. Improving these areas enhances confidence, efficiency, and user trust in the application.
Solution
  • Introduced guided onboarding or step-by-step setup wizards.

  • Provideed inline validation (e.g., “This field is mandatory” or “Invalid IMO number”).

  • Used clear labeling and consistent iconography across modules.

  • Implemented responsive design with adaptive layouts for all devices.

  • Maintained UI consistency between desktop and mobile apps.

  • Provided clear feedback messages,Used color-coded notifications for errors, warnings, and confirmations, Replace technical jargon with user-friendly explanations.
Results
  • Reduced profile setup time by up to 40–50% With guided onboarding and auto-validation - Higher user confidence and faster onboarding for new planners.

  • Improved Navigation & Information Accessibility Reduced cognitive load — planners locate data intuitively based on clear hierarchy.
    Increased daily task efficiency and reduced training dependency.

  • Smarter Notification System Reduced notification overload — only relevant alerts reach each planner.

  • Consistent Cross-Platform Experience Seamless use of the system across desktop, tablet, and mobile.

  • Strengthened Security & Trust Users feel in control of their data with clear visibility and privacy options.
Category 🔴 Before 🟢 After Implementation
User Efficiency Complex, time-consuming setup Simplified, guided setup process
Navigation Scattered and confusing Structured, intuitive layout
Personalization One-size-fits-all interface Fully customizable user dashboard
SFeedback & Trust Low confidence due to unclear errors High trust with clear communication
Engagement & Adoption Moderate Significantly increased across users
Post-implementation, the Marine Fleet Planner profile experience becomes intuitive, efficient, and empowering, leading to:

  • Higher user satisfaction and adoption

  • Reduced operational errors

  • Faster onboarding and decision-making

  • Stronger collaboration and compliance
